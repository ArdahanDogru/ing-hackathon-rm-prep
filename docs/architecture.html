2. Annotations (numbers match the diagram)

#WhereWhat happensWhy
1pipeline.ingestThe only code that reads the clock, the network, .env, the inbox folders and the current sources.yaml.Keeps every outside input in one place, so everything after the snapshot can be replayed.
2config.pyChecks types, unknown keys, quantity references and a required tos_note for each source. Errors name the key path.A typo stops the run before any data is fetched.
3adapters/evds.pyOne GET for each series. The key goes in the key header, never in the URL. VERIFY_ codes get no request. Each response is parsed in memory before it is stored.A stored payload always parses on replay, and the key is never stored.
4adapters/tefas.pyCopies hand-exported files byte for byte. Matches headers through aliases and reads Turkish numbers and dates. The module imports no HTTP client.Follows the no-scraping rule.
5adapters/manual.pyValidates each row. Rejected rows go into the manifest with their reasons, and accepted rows get manual_entry.Every manual value has a source URL and a date.
6pipeline._apply_failure_policyA failed source (no key, HTTP error, empty inbox, bad file) gets fallback_from (last snapshot where the source was ok) or excluded: true.You choose the policy for each source in sources.yaml.
7snapshot.pyWrites to .tmp-{id}, writes the manifest and its hash, makes the files read-only, then renames the folder. The manifest is refused if it contains the API key.A snapshot is complete or absent, never partly written or changed.
8pipeline.build_evidencePure function of (snapshot bytes, manifest, exclude set). The staleness date is the snapshot created_at, not today.Same snapshot + same exclusions gives the same output.
9snapshot.open_snapshotChecks the manifest hash and each payload hash, and rejects extra files.A changed snapshot cannot be replayed without notice.
10pipeline._source_pointsRe-parses the older snapshot named in fallback_from. Rows get the new snapshot_id and the fallback_snapshot flag, but keep their original raw_ref and fetched_at. If there is no older snapshot, EVDS gives missing rows.Old data is used openly, never presented as new.
11build_evidence(..., exclude_sources)Removes the excluded sources before the checks.A conflict caused only by a crossed-out source disappears.
12quality.pyAdds flags and notes only; values never change.The raw evidence stays intact; flags explain the problems.
13store.pyLoad = delete + insert in one transaction (idempotent). is_latest = rows of the newest snapshot by created_at. Times are stored in Turkey time.Replaying an old snapshot does not make it the latest.
14store.export_parquetContract columns only, sorted by id. is_latest is not exported.Replay gives a byte-identical file.
