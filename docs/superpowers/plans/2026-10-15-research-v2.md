# Web araştırması v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A compact, structured research block per product: dated "Son haberler" (last 90 days, newest first) and at most 4 short "Öne çıkanlar" bullets with fixed topics, without facts the RM already has and without repeats; RM answers in the same bullet form.

**Architecture:** Exa makes two calls per product (highlights with a per-kind schema; news with `category: "news"` and `startPublishedDate`). A new pure module `rmprep.research.shape` shapes every provider's result in the service (word cut, known-fact filter, repeat filter, caps, news window and order), so Exa and the Claude fallback give the same shape. Cache files gain the version (`-v2`). The panel shows one compact block per product with a closed source list.

**Tech Stack:** Python 3.11, httpx, anthropic (fallback), FastAPI; React 18 + TypeScript, vitest, Tailwind.

**Spec:** the approved v2 design (ing-lead message relayed by the user, 2026-10-15), recorded here in "Design" below; the v1 spec `docs/superpowers/specs/2026-10-14-exa-research-design.md` and `docs/research.md` still bind everything v2 does not change.

## Design (approved by the user 2026-10-15; controller choices marked *)

1. Two Exa calls per product. (a) NEWS: `category: "news"`, `startPublishedDate` = today − `news_days` (90); query from the company name (or the label when no company) and the code; `kap.org.tr` excluded, republishers allowed; at most `news_max` (3) items, each {date, sentence ≤ 20 words, source}; newest first. (b) HIGHLIGHTS: the product call with a per-kind schema: at most `highlights_max` (4) bullets, each ≤ 20 words, topics funds/ETFs: `strateji`, `yonetici_sirket` (at most one bullet), `dikkat`; shares: `is`, `finansal`, `sermaye`. *The long summary is dropped (`summary` is always "").
2. Less repetition: a highlights prompt says not to repeat code, ISIN, launch date, umbrella fund, custodian, founder, SPK risk value, returns or fees; in code, a highlight that contains a `known_terms` entry is dropped, and a bullet whose word set has Jaccard ≥ `repeat_jaccard` (0.6) with an earlier kept bullet is dropped; counts go to `checks`. *The known-term filter applies to highlights only (not news, not RM answers: the RM may ask about fees).
3. Panel: per product a name line (label, company); "Son haberler" dated bullets newest first, or "Son {n} günde haber bulunamadı."; "Öne çıkanlar" bullets; each bullet ends with source numbers like `[1, 2]`; sources in a closed `<details>` "Kaynaklar (n)"; the confidence mark only when low; the label "web kaynağı, doğrulanmamış" stays; RM answers in the same bullet form; TR and EN.
4. Cost about $0.025 per product (deep highlights $0.012 + auto news $0.007 + contents); the $2 daily limit stays; *the cache key gains the version (`…-v2.json`), so v1 files are never shown.
5. Unchanged: no effect on scores or meeting text; only the API starts research; no persona data to providers; the Claude fallback gives the same shape with `news` empty and a check note.

2. The highlight that carries the company fact must not be dropped just because it names the company; but "kurucu"/"founder"/"saklayıcı" bullets are dropped (AIS example).

```python
"""Web araştırması v2 shaping (docs/research.md "v2"): short bullets, no facts the
RM already has, no repeats, caps; news only inside the window, newest first. The
service runs it on every provider's result, so Exa and Claude give one shape."""

from __future__ import annotations

import dataclasses
import re
import unicodedata
from collections.abc import Iterable, Sequence
from datetime import date, timedelta

from rmprep.research.checks import _words, tr_lower
from rmprep.research.config import ShapeConfig
from rmprep.research.types import SHAPE_VERSION, Finding, ProductResearch, QuestionAnswer

COMPANY_TOPICS = ("yonetici_sirket",)    # at most one bullet of these topics


def cut_words(text: str, max_words: int) -> str:
    """The text, or its first max_words words and "…"."""
    words = text.split()
    if len(words) <= max_words:
        return text.strip()
    return " ".join(words[:max_words]).rstrip(",;:") + "…"


def _tokens(text: str) -> set[str]:
    return {w for w in _words(text) if len(w) >= 3}


def _jaccard(a: set[str], b: set[str]) -> float:
    return len(a & b) / len(a | b) if a | b else 0.0


def _fold(text: str) -> str:
    """NFC, Turkish lower-casing, ı -> i (so "ISIN" -> "ısın" still matches "isin")."""
    return tr_lower(unicodedata.normalize("NFC", text)).replace("ı", "i")


def _has_known_term(text: str, terms: Iterable[str]) -> bool:
    low = _fold(text)
    return any(re.search(r"(?<!\w)" + re.escape(_fold(t)), low) for t in terms)


def _tidy(items: Sequence[Finding], cfg: ShapeConfig, cap: int, *,
          known: bool) -> tuple[list[Finding], list[str]]:
    """Known-fact filter (highlights only), repeat filter, word cut, cap; check lines."""
    kept: list[Finding] = []
    n_known = n_repeat = 0
    for f in items:
        if known and _has_known_term(f.text, cfg.known_terms):
            n_known += 1
            continue
        if any(_jaccard(_tokens(f.text), _tokens(g.text)) >= cfg.repeat_jaccard for g in kept):
            n_repeat += 1
            continue
        kept.append(dataclasses.replace(f, text=cut_words(f.text, cfg.bullet_max_words)))
    checks = []
    if n_known:
        checks.append(f"{n_known} bullets dropped (known facts)")
    if n_repeat:
        checks.append(f"{n_repeat} bullets dropped (repeats)")
    return kept[:cap], checks + ([f"{len(kept) - cap} bullets over the cap"] if len(kept) > cap else [])


def _one_company_bullet(items: Sequence[Finding]) -> tuple[list[Finding], int]:
    out, seen, dropped = [], False, 0
    for f in items:
        if f.topic in COMPANY_TOPICS:
            if seen:
                dropped += 1
                continue
            seen = True
        out.append(f)
    return out, dropped


def _in_window(f: Finding, start: date, today: date) -> bool:
    try:
        d = date.fromisoformat(f.date)
    except ValueError:
        return False
    return start <= d <= today


def shape_product(p: ProductResearch, cfg: ShapeConfig, today: date) -> ProductResearch:
    if p.error:
        return dataclasses.replace(p, summary="", news_days=cfg.news_days, version=SHAPE_VERSION)
    checks = list(p.checks)
    highlights, n_company = _one_company_bullet(p.findings)
    if n_company:
        checks.append(f"{n_company} company bullets dropped (one allowed)")
    highlights, more = _tidy(highlights, cfg, cfg.highlights_max, known=True)
    checks += more
    start = today - timedelta(days=cfg.news_days)
    dated = [n for n in p.news if _in_window(n, start, today)]
    if len(dated) < len(p.news):
        checks.append(f"{len(p.news) - len(dated)} news items undated or outside {cfg.news_days} days dropped")
    dated.sort(key=lambda n: n.date, reverse=True)
    news, more = _tidy(dated, cfg, cfg.news_max, known=False)
    checks += [c.replace("bullets over the cap", "news items over the cap") for c in more]
    return dataclasses.replace(p, findings=tuple(highlights), news=tuple(news), summary="",
                               news_days=cfg.news_days, version=SHAPE_VERSION, checks=tuple(checks))


def shape_answer(a: QuestionAnswer, cfg: ShapeConfig) -> QuestionAnswer:
    if a.error:
        return dataclasses.replace(a, summary="", version=SHAPE_VERSION)
    bullets, more = _tidy(a.findings, cfg, cfg.highlights_max, known=False)
    return dataclasses.replace(a, findings=tuple(bullets), summary="", version=SHAPE_VERSION,
                               checks=a.checks + tuple(more))
```
