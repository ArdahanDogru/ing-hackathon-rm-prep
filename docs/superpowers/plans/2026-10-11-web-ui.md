# Web UI Implementation Plan

> **For agentic workers:** this plan runs in the project's multi-agent workflow
> (`docs/workflow.md`): ing-lead does the L tasks on `main`; each worker does
> its own tasks test-first in its worktree and reports
> "milestone <n> done, tests green, <branch>@<sha>". Steps use checkbox
> (`- [ ]`) syntax for tracking. Read `docs/web-ui.md` (the spec) before your
> first task.

**Goal:** Replace the Streamlit page with a custom web app (dashboard, fund
card, meeting text) on a JSON API over `RealBackend`, with the engine and
narrator data that the screens need.

**Architecture:** FastAPI package `src/rmprep/api/` (lead) wraps the
`Backend` protocol, keeps its own run registry, and builds view models; the
React app in `web/` (worker `ing-web`) reads only the API. Decision (D16–D18)
and narrator (N9) add the client/RM split, display facts, talking points and
need tags (contract v1.3, additive). `python -m rmprep serve` serves both on
`http://127.0.0.1:8600`.

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, pytest + `fastapi.testclient`;
Node 24, Vite, React 18, TypeScript, Tailwind CSS 3, Vitest, Testing Library,
`@fontsource/inter`.

**Spec:** `docs/web-ui.md` (screens: "Decisions"; technical: sections 1–9),
mockups `docs/web-ui/mockups/`.

## Global Constraints

- Python `>=3.11`, no 3.12-only features; all timestamps `Europe/Istanbul`.
- Every task ends with green `pytest` (full suite); no test touches the network.
- Contract v1.3 is additive: every new field has a default; v1.2 JSON still loads.
- The API adds no business rules; numbers that need stopaj, CPI or priorities come from decision.
- Theme: ING orange `#FF6200` only for the brand and the main buttons; text `#1D2440`; chart cobalt `#4676BF`; category grey `#D0D5DD`; no orange in charts.
- SPK risk colors: 1 `#12B76A`, 2 `#66C61C`, 3 `#A6C612`, 4 `#F79009`, 5 `#EF6820`, 6 `#E04F16`, 7 `#D92D20`; all filled segments take the fund's level color.
- Stars: top 10 % = 5, next 22.5 % = 4, middle 35 % = 3, next 22.5 % = 2, bottom 10 % = 1; share = `(p − 1) / n`.
- Match ring: `10 × (n − position) / (n − 1)`, one decimal, deposit baseline not counted, n = 1 → 10.
- No raw score numbers on any screen; RM-only warnings never in client-facing text.
- An open category shows at most 3 funds (head first), no "more" button.
- Server binds `127.0.0.1`, port 8600 by default; no login.
- Files use LF line endings; `web/dist/` and `web/node_modules/` are not in git.
- At most 3 sessions work at the same time, the lead included.

## Review Focus

1. **A fund without a 1-year return** (short history, missing row): no rank, no stars, "sıralama yok"; the category average ignores it; nothing crashes. Test: L5 `test_option_view_without_1y`.
2. **A run id after a server restart** (registry empty): the API answers 404 with a clear detail, the web makes the run again with the same inputs and gets the same id. Tests: L4 `test_unknown_run_404`, W2 `retries a 404 run`.
3. **A test run (edited persona)**: approval returns 422 with the backend message; the web disables approval with the reason before any call. Tests: L4 `test_test_run_cannot_be_approved`, W4 `test run disables approval`.
4. **The meeting text takes long or fails** (LLM slow, no key, budget): the API waits at most 120 s and returns 504; a template draft shows its banner. Tests: L6 `test_narrative_timeout_504`, W5 `shows the template banner`.
5. **A persona priority with Turkish characters** ("sınırlı dalgalanma", "İ"/"ı" casing) in need tags and `why`: matched with Turkish lower-casing, shown as written in the persona. Tests: N9 `test_need_tags_turkish_case`, D17 `test_why_uses_persona_wording`.

```python
"""JSON API over the Backend protocol (docs/web-ui.md sections 1, 6, 8; lead-owned).
No business rules here: values come from the engine, the view module only arranges them."""

from __future__ import annotations

from pathlib import Path

from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import JSONResponse

from rmprep.api import schemas
from rmprep.contracts import Backend, DecisionResult, Persona, RmStatus


def create_app(backend: Backend, *, views=None, static_dir: Path | None = None,
               narrative_timeout_s: float = 120.0) -> FastAPI:
    app = FastAPI(title="rmprep")
    runs: dict[str, DecisionResult] = {}

    @app.exception_handler(ValueError)
    async def _value_error(_: Request, exc: ValueError):
        return JSONResponse(status_code=422, content={"detail": str(exc)})

    def _original(persona: Persona) -> Persona | None:
        return next((p for p in backend.list_personas() if p.persona_id == persona.persona_id), None)

    def _changes(persona: Persona) -> list[dict]:
        orig = _original(persona)
        if orig is None:
            return []
        a, b = orig.to_dict(), persona.to_dict()
        return [{"field": k, "original": a[k], "edited": b[k]} for k in a if a[k] != b[k]]

    def _view(result: DecisionResult) -> dict:
        runs[result.run_id] = result
        changes = _changes(result.persona)
        base = {"result": result.to_dict(), "test_run": bool(changes), "persona_changes": changes}
        if views is not None:
            base.update(views.build(result))
        return base

    def _run(run_id: str) -> DecisionResult:
        if run_id not in runs:
            raise HTTPException(404, f"unknown run {run_id} (the server may have restarted)")
        return runs[run_id]

    @app.get("/api/personas")
    def personas():
        return [p.to_dict() for p in backend.list_personas()]

    @app.get("/api/snapshots")
    def snapshots():
        return backend.list_snapshots()

    @app.get("/api/snapshots/{snapshot_id}/sources")
    def sources(snapshot_id: str):
        ev = backend.evidence(snapshot_id)
        return {k: (v.to_dict() if hasattr(v, "to_dict") else str(v)) for k, v in ev.source_status.items()}

    @app.post("/api/runs")
    def new_run(req: schemas.RunRequest):
        persona = Persona.from_dict(req.persona)
        snap = req.snapshot_id or backend.list_snapshots()[0]
        return _view(backend.decide(persona, snap, frozenset(req.exclude_sources)))

    @app.get("/api/runs/{run_id}")
    def get_run(run_id: str):
        return _view(_run(run_id))
```

```python
def stars(position: int, n: int) -> int:
    share = (position - 1) / n
    for limit, s in ((0.10, 5), (0.325, 4), (0.675, 3), (0.90, 2)):
        if share < limit:
            return s
    return 1


def match(position: int, n: int) -> float:
    return 10.0 if n <= 1 else round(10 * (n - position) / (n - 1), 1)
```
